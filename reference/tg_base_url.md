# The API base URL in use

Reports the base URL requests are sent to. Set the
`transferegovr.base_url` option to point the package at a mirror or a
test double.

## Usage

``` r
tg_base_url()
```

## Value

A single string.

## Examples

``` r
tg_base_url()
#> [1] "https://api-publica.transferegov.gestao.gov.br"
```
